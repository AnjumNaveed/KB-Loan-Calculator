# KB Loan Calculator & Lead CRM (Web & PWA Version)
### آئی فون، اینڈرائیڈ اور کمپیوٹر کے لیے مکمل پروگریسو ویب ایپ (Progressive Web App)

یہ فولڈر مکمل طور پر تیار شدہ (Standalone HTML, CSS, JS) ویب ایپ فائلوں پر مشتمل ہے، جس میں کسی قسم کی `npm` یا کوڈ کمپائل کرنے کی ضرورت نہیں ہے۔ آپ ان فائلوں کو براہِ راست گٹ ہب (GitHub) پر اپلوڈ کر کے بالکل مفت میں لائیو ویب سائٹ اور آئی فون ایپ بنا سکتے ہیں۔

---

## 🚀 گٹ ہب پر لائیو کرنے کے دو طریقے (Publishing Methods)

### طریقہ 1 (انتہائی آسان اور آٹومیٹک - AI Studio کے ذریعے):
1. **AI Studio میں Push to GitHub دبائیں:**
   * اس اسکرین کے اوپر دائیں کونے میں **Settings** یا **Export / Push to GitHub** بٹن پر کلک کریں۔
   * اپنے GitHub اکاؤنٹ سے لاگ ان کریں اور کوئی بھی نام رکھیں (مثلاً `kb-loan-crm`) اور **Push** کر دیں۔
2. **گٹ ہب پر GitHub Actions آن کریں:**
   * اپنے GitHub اکاؤنٹ پر اس ریپازیٹری میں جا کر **`Settings` ➔ `Pages`** پر جائیں۔
   * **Build and deployment** میں **Source** کو `Deploy from a branch` کے بجائے **`GitHub Actions`** پر سیٹ کر دیں۔
3. **لائیو!** ہم نے پراجیکٹ کے اندر خودکار ورک فلو (`.github/workflows/deploy-pwa.yml`) لگا دیا ہے جو خود بخود ویب ایپ کو 45 سیکنڈ کے اندر فری لائیو کر دے گا۔

---

### طریقہ 2 (براہِ راست فائلیں ڈریگ اینڈ ڈراپ کرنا):
1. [GitHub.com](https://github.com) پر نیا پبلک ریپازیٹری بنائیں۔
2. اس `web-pwa` فولڈر کی 5 فائلیں (`index.html`, `styles.css`, `app.js`, `manifest.json`, `sw.js`) اپلوڈ کر کے Commit کر دیں۔
3. **Settings ➔ Pages** میں جا کر **Branch: main** منتخب کر کے **Save** کر دیں۔

---

## 📱 آئی فون (Apple iPhone / iOS) پر ایپ انسٹال کرنے کا طریقہ

1. اپنے آئی فون میں **Safari براؤزر** کھولیں اور گٹ ہب پیجز والا لنک اوپن کریں۔
2. نیچے اسکرین پر موجود **Share بٹن** (مربع کے اوپر تیر کا نشان ⎋) دبائیں۔
3. نیچے اسکرول کریں اور **`Add to Home Screen`** منتخب کریں۔
4. اوپر دائیں کونے میں **`Add`** دبائیں۔
5. **مبارک ہو!** ایپ کا آئیکن آپ کے آئی فون کی ہوم اسکرین پر آ جائے گا۔ اب جب بھی آپ اسے کھولیں گے، یہ بنا کسی براؤزر بار کے بالکل اصل آئی فون ایپ کی طرح فل اسکرین اور **100% آف لائن** چلے گی!

---

## 🤖 اینڈرائیڈ موبائل پر انسٹالیشن (Google Chrome)

1. گوگل کروم میں گٹ ہب والا لنک کھولیں۔
2. اوپر دائیں کونے میں تھری ڈاٹس (**⋮**) پر کلک کریں۔
3. **`Install app`** یا **`Add to Home screen`** دبائیں۔

---

## 🔄 گوگل شیٹ کے ساتھ آف لائن سنکنگ (Offline Syncing Engine)

1. ایپ کھول کر **`Settings`** والے ٹیب پر جائیں۔
2. اپنا نام، اسٹاف آئی ڈی، برانچ اور وہی **Google Sheets Webhook URL** درج کریں جو آپ کی اینڈرائیڈ ایپ میں چل رہا ہے۔
3. **`Save Profile`** کر دیں۔
4. اب چاہے انٹرنیٹ بند ہو یا موبائل فلائٹ موڈ پر ہو، آپ کسٹمرز کے لون اور ڈپازٹس کا حساب لگا سکتے ہیں اور لیڈز فون میں محفوظ کر سکتے ہیں۔
5. جیسے ہی موبائل انٹرنیٹ سے جڑے گا، تمام جمع شدہ لیڈز اور کال/واٹس ایپ کا ٹریک ریکارڈ خودکار طور پر گوگل شیٹ میں جا کر اپ ڈیٹ ہو جائے گا۔

---

## 📂 فائلز کی تفصیل (Project Architecture)

- **`index.html`**: جدید ریسپانسو UI، جس میں لون و ڈپازٹ کیلکولیٹر، لیڈز مینیجمنٹ، اور ہسٹری لاگز شامل ہیں۔
- **`styles.css`**: موبائل فرسٹ مٹیریل ڈیزائن 3 اسٹائلنگ، جو آئی فون کے سیف ایریا اور اینڈرائیڈ دونوں کے مطابق پرفیکٹ ہے۔
- **`app.js`**: تمام ریاضی، ڈی بی آر رولز، انڈیکسڈ ڈی بی (IndexedDB) آف لائن اسٹوریج، اور گوگل شیٹ سنکنگ کا مکمل جاوا اسکرپٹ کوڈ۔
- **`manifest.json`**: پروگریسو ویب ایپ کی سیٹنگز جو موبائل کو بتاتی ہیں کہ یہ ایک انسٹال ایبل ایپ ہے۔
- **`sw.js`**: سروس ورکر جو تمام فائلوں کو فون کی کیشے میں محفوظ کر کے بنا انٹرنیٹ کے ایپ چلاتا ہے۔
